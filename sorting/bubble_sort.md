# Bubble Sort

Repeatedly swap adjacent elements in a list or array if they are in the wrong order

Algorithm can iterate through the array multiple times. In each pass, the
largest unsorted element is pushed to its correct position

If no swaps are made during a pass, the array is already sorted, so we stop the
sorting process.

After each full pass, the largest unsorted element is essentially "bubbling up" to the correct position at the end.
