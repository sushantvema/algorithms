# Tim Sort

Tim sort is a hybrid sorting algorithm derived from [[merge-sort]] and
[[insertion-sort]]. 

Designed to perform well on different kinds of real-world data. 

Exploits structure present in the data such as runs (consecutive sequences that
are already ordered) and merges these runs using a modified merge sort approach. 

Created by Tim Peters in 2002. Default sorting algorithm in Python and renowned
for speed and efficiency.
