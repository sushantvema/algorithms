# Insertion Sort

Iteratively insert each element of an unsorted list into its correct position in
a sorted portion of the list.

First calculate length of the array. If the length is 0 or 1, the function
returns immediately.

With more than one element, start with the second element of the array as the
first element in array is assumed to be sorted.

Compare second element with first element and check if second element is smaller
then swap them. 

Move to third element and compare it with first two elements and pput at correct
position.

Repeat until entire array is sorted.
